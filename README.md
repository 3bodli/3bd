# 3bod – خطوات التشغيل

## 1) قاعدة البيانات (Supabase – مجانية)
1. أنشئ حساباً على supabase.com ثم **New project**.
2. من **SQL Editor** الصق محتوى `supabase/schema.sql` كاملاً واضغط **Run**.
3. من **Authentication > Providers > Email** أطفئ **Confirm email** (لأنك بدك بدون تحقق).
4. من **Project Settings > API** انسخ **Project URL** و **anon public key** وحطّهم في `js/config.js`.
   (مفتاح anon آمن للنشر، لكن لا تضع أبداً مفتاح `service_role` في الملفات.)

## 2) حساب الأدمن
كلمة سر الأدمن ما بتنكتب داخل الكود لأنه أي حدا بيشوف الكود بيعرفها. الطريقة الآمنة:
1. افتح الموقع (`index.html`) وأنشئ حساباً عادياً ببريدك.
2. في Supabase SQL Editor شغّل:
   `update profiles set is_admin = true where email = 'بريدك';`
3. ادخل على `/admin.html` بنفس البريد وكلمة المرور.

## 3) النشر
ارفع المجلد كاملاً كما هو على Cloudflare Pages أو Netlify أو GitHub Pages. لا يحتاج أي بناء.

## 4) الإعدادات (`js/config.js`)
`RATE_SYP` سعر الليرة مقابل الدولار، `FEE_PCT` و`FEE_MIN` العمولة، `CASHOUT` ما بتاخده من الدولار لكل 1 USDT (196/205)، `SHAM_FEE` عمولة شام كاش، و`PAY` عنوان محفظتك.

## ملاحظات مهمة
- الخطة المجانية بتوقف المشروع (pause) بعد أسبوع بدون نشاط، وبتفعّله من لوحة Supabase يدوياً.
- حسابات المبالغ بتصير في المتصفح، فقبل ما تأكّد أي حوالة قارن "المطلوب (USDT)" الظاهر في الأدمن مع المبلغ الواصل فعلياً لمحفظتك.
- لا تأكّد الدفع إلا بعد ما تشوف المبلغ بمحفظتك، مو بس باللقطة.
